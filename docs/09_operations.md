# 運用手引き（下書き）

回覧板を自治体・避難所で使うための手順書。対象は防災課（本部）、避難所の運営者、運び役（消防団・民生委員・物資車両）。docs/08 C16 の内容を、今のアプリの画面と文言に合わせて書く。

- 状態: **下書き（2026-11-13）**。【実測待ち】の数値は実機テスト（Redmine #120〜#128）で埋め、第 4 周（#130）で利用者に読んでもらって直す。
- ボタン名は「」で、アプリの表示どおりに書く。
- 「（未実装）」と書いた操作は、今のアプリにはない。

## 0. はじめに知っておくこと

| 項目 | 内容 |
|---|---|
| 何をするアプリか | 近くのスマホどうしが Bluetooth で、お知らせを複製して運ぶ。サーバ・インターネット・ペアリングは使わない |
| 届く距離 | 未実測。従来の 10〜30 m は見込みで、端末や障害物で変わる【実測待ち #125】 |
| 1 回の交換で運べる量 | 通常は最大 64 KiB。通信単位が小さい場合はさらに下がる。足りなければ約 2 秒後に続きを送り、1 回のすれ違いで複数回交換することもある。件数は本文量で変わる |
| 送る順 | SOS と避難情報 → 取り消し・受け取りました → 無事です・在宅避難 → 公式の給水・避難所など → 住民の投稿 → 訓練 |
| かかる時間 | 過去の Mac → iPhone 17 の実測は 300 件 2.4 秒、1,500 件 28 秒。最新版や歩行中の値ではなく、相手を見つけるまでの時間も別途確認が必要【実測待ち #121】 |
| 1 台に保存できる数 | 中継用は最大 3,000 件。有効な未確認 SOS を容量都合で消さず、削除候補がなければ保存エラーにする。本部・スタッフの報告と返信は別に最大 10,000 件・64 MiB・30 日保存する |
| 画面を消したとき | 初対面の iPhone どうしが両方画面オフの状態では、自動交換を保証しない。固定した中継端末はアプリを前面で開き、画面を点けて待ち受ける。Android の機種差を含め、背景動作の実機確認は残っている |
| 全体に届いたか | サーバがないので分からない。「この端末から 渡した: N台」は、この端末が直接渡した台数（下限）だけ |

Bluetooth を ON にするだけでなく、両方でアプリを起動し、初期設定・Bluetooth の許可・通信 ON を済ませる。毎回の送信操作やペアリングは不要。[通信時間と歩行中の試算](13_ble_encounter_estimates.md)の「約 700 件」は、片方静止・秒速 1.2 m・半径 10 m・接続待ち 3 秒という仮定での計算で、画面オフで歩いたときの実測ではない。

**アプリは「写し」**。避難指示・津波警報は、防災行政無線・緊急速報メール・テレビ・ラジオ・声が正しい情報。アプリは届くまで時間がかかり、届かないこともある。

## 1. 平時の準備（防災課）

### 1.1 市のグループを作る

1. 本部用の端末（2 台。1 台は Android）にアプリを入れる。表示名は「〇〇市 防災課」のように役割が分かる名前にする。
2. 「グループ」→「グループを 作る」。名前（例: 〇〇市 防災）、問い合わせ先を入れる。
3. 「投稿の 決まり」は **「参加者も 投稿できる」をオフ**にする（デマの拡散を防ぐ。住民の困りごとは 4 章の「住民からの 知らせ」で受ける）。
4. 「住民からの 知らせを 受け付ける」は、知らせを見る係（本部・スタッフ）を置いてからオンにする（あとで変えられる）。
5. 作ると **参加コード（6 桁）**、**本部コード（8 桁）**、**スタッフコード（8 桁）** が出る。

### 1.2 コードの扱い

| コード | 誰に | どう保管・配布するか |
|---|---|---|
| 参加コード（6 桁） | 住民全員 | ハザードマップ・広報誌・自治会の回覧・避難所の掲示に印刷する（QR コードも出せる）。**変えない** |
| 本部コード（8 桁） | 防災課の担当者 | 紙に書いて防災課の金庫で保管。2 台目の本部端末は「本部コードを 入れる」で本部にする |
| スタッフコード（8 桁） | 協定先（病院・薬局・電力・ガス・水道・通信・燃料・交通・金融）、避難所の運営者 | 封筒で配る。年 1 回の訓練で「コードを 作り直す」で新しくし、配り直す |

- コードを入れた端末は「公式」「スタッフ」として表示され、取り消し・書きなおしの権限を持つ。
- **漏れたとき**: 「コードを 作り直す」は、それ以後にコードを入れる端末にだけ効く。すでに昇格した端末は降格できない。完全に止めるには新しいグループを作って参加コードを配り直す（「新しい グループに 引っ越す」は未実装）。管理台帳（誰に・いつ・何番を渡したか）を防災課で持つ。

### 1.3 年 1 回の点検

- [ ] 本部端末 2 台が動く（通信を 始める → 近くの端末に届く）
- [ ] 「グループの 情報を もう一度 広げる」を押す（グループ名などの情報は 1 年で期限が切れるため）
- [ ] 掲示用の紙（7 章）を新しくする
- [ ] 1 日の電池の減りを測り直す【実測待ち #128】
- [ ] 訓練（6 章）を 1 回行う
- [ ] 担当交代があれば、新しい端末で参加 → 「本部コードを 入れる」。お知らせを出す前に端末の時計が合っているか確かめる（ずれていると書く画面に警告が出る）

## 2. 発災時の配置（避難所の運営者）

### 2.1 中継役の端末を置く

自治体が配る Android 端末を「中継役」にして、人が通る場所に置く。

1. 端末で参加コードを入れて参加する（本部コードは入れない）。
2. 「設定」→「中継役として 使う」。画面が点いたままになり、交換が終わるたびに短い音と振動で知らせる（「交換の 音: 鳴らさない」で止められる）。
3. 充電器につなぎ、画面を点けたままにする。「電池の 最適化から 除外する」を押しておく。

| 置く場所（各 1 台） | 置き方 |
|---|---|
| 避難所の受付、駐車場側の出入口 | 入口から 10 m 以内（目安【実測待ち #125】）。金属の棚・箱の中に入れない |
| 給水所、物資の配布所 | 列のそば。並んでいる間に交換できる |
| 巡回バスの車内 | 停車中に交換される（走行中は届きにくい） |
| 病院・薬局・ガソリンスタンドの受付 | 協定先にお願いする |

- 中継役どうしは 1 回に 1 MB・300 秒まで交換する（運び役の端末も中継役にすると、出発前の受け取りが速い）。
- 中継役の端末は、参加しているグループ名を近くの端末に知らせる（私物の端末は知らせない）。

### 2.2 1 日 1 回の確認

「設定」→「通信の 状態を 見る」で確かめる。

- [ ] 「近くの端末」が 1 台以上
- [ ] 「最後に 交換した」が数時間以内
- [ ] 「保存件数」が増えている（3,000 件に近ければ古いものから入れ替わる）
- [ ] 「最後に 渡したのは」が更新されている
- [ ] Android なら「近くの人と 情報を 交換しています」の通知が出ている（消すと止まる機種がある）

## 3. 運び役（消防団・民生委員・物資車両）

| 場面 | すること |
|---|---|
| 出発前 | 本部端末または中継役の横でアプリを開き、通信の状態を確認する。「最後に 受け取ったのは」や交換完了の音だけで全件そろったとは判断しない。1,500 件・28 秒は過去の Mac → iPhone の実測で、他の条件は確認待ち【#121】 |
| 戸別訪問 | 1 軒 3 分のうち、玄関先で 30 秒立ち止まる（目安【実測待ち #125】）。相手が iPhone なら、アプリを開いてもらう |
| 車 | 止まって 1〜2 分待つ。走行中は届かない |
| 帰ったら | 本部の横でもう一度待つ（集めた「住民からの 知らせ」が本部に届く） |

- 自分の端末で「この端末から 渡した: N台」を見ると、直接渡した台数が分かる（その先は分からない）。
- ドローン・バイクでの運搬は、実測するまで手順に書かない。

## 4. 住民からの知らせ（SOS・無事です・在宅避難・困っています）

1. グループの「住民からの 知らせを 受け付ける」をオンにすると、住民の画面に「本部に 知らせる」が出る。
2. 本部・スタッフの端末には「住民からの 知らせ」の帯が出て、SOS は緊急の通知で知らせる。
3. 一覧で中身を確かめ、「受け取りました」を押す（まとめて押せる）。返事は送った本人に届く。**「受け取りました」は対応の約束ではない**ことを住民に説明しておく。
4. 安否確認をするときは、お知らせを書く画面で「返事の ボタンを 付ける（安否確認）」をオンにする。住民は「無事です」「家に います」「困っています」「助けて」で返事でき、本部は安否確認ごとに集計できる。
5. 集計は「表示中の 知らせを 文章で コピー」で写して、無線・紙の記録に写す。

- 住民からの知らせは本部・スタッフの画面にだけ出るが、暗号化はしていない（運んだ端末の中には残る）。
- いたずらの SOS は防げない（同じ人の送り直しを 10 分止めるだけ）。現地で確かめてから動く。

## 5. 公式のお知らせの書き方

- 見出しに **どこで・いつから・いつまで** を入れる（見出しは 40 文字まで）。例文の { } の部分は必ず書きかえる。
- **1 施設 1 端末**で、発信元名は施設名にする（「発信元名を 変える」）。
- 内容が変わったら新しく出さず「書きなおす」（古い版は近くの端末で置き換わる）。
- 売り切れ・満員・閉鎖は「終わりました」。
- 期限は短めにする（既定は給水・炊き出し 12 時間、避難所 7 日など種別ごとに決まっていて、書く画面で 7 択と時刻から選べる）。
- 詳細画面の「掲示番号」（6 桁）を、紙の掲示板に「種別＋番号」で書いておくと、紙とアプリを突き合わせられる。

## 6. 訓練

1. 書く画面で「これは 訓練です」をオンにする。見出しに【訓練】が付き、送る順が最後になる。
2. 終わったら、グループの詳細の「訓練の お知らせを すべて 取り消す」。
3. 訓練で確かめること: 本部端末 2 台・中継役・運び役で、指定の場所まで何分で届くか（記録してこの手引きの数値を直す）。

## 7. デマへの対応

1. 現地または電話・無線で事実を確かめる。
2. 公式端末で、そのお知らせを開き「公式として 取り消す」。正しい内容があれば「取り消して 新しく 書く」。取り消すと、本文は近くのスマホからも消える（届くまで時間がかかる）。
3. 住民の投稿が続くなら、グループの詳細で「参加者も 投稿できる」をオフにする。
4. 本部へ無線で報告する。取り消しの記録を公表する（アプリ内の「公式取消の 記録」は未実装。紙に「掲示番号・見出し・時刻・理由」を残す）。

## 8. 掲示板に貼る紙（A4 1 枚）

```
【回覧板アプリ】〇〇市 防災

  参加コード:  1 2 3  4 5 6        （QR コード）

  1. アプリを 開いて「グループに 参加する」
  2. 6 桁を 入れるだけ
  3. アプリを 開いたまま 待ち、通信の 状態を 確かめてください

  ・避難の 呼びかけは 防災無線・ラジオが 正しい 情報です
  ・困ったときは「本部に 知らせる」から 送れます（受付している 場合）
```

## 9. 利用者への説明（プライバシー・利用規約の要点）

アプリの「知っておいて ほしいこと」（はじめに・設定）と同じ内容にする。

- 表示名は任意で、本名でなくてよい。電波に乗るのはアプリの目印（番号）だけ。
- お知らせは暗号化していない。近くのスマホを通って広がり、受け取った端末から消すことはできない（取り消しは届くまで時間がかかる）。
- 新しい版のお知らせは、中身を確かめずに運ぶことがある。
- 16 歳未満は保護者と使う。
- 「受け取りました」は対応の約束ではない。
