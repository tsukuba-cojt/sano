# 回覧板（すれ違い通信アプリ）テスト仕様書

第 2 版 2026-11-04（開発者メニューでの実測と修正を追記）。Excel 版は [テスト仕様書.xlsx](テスト仕様書.xlsx)（同じ内容、`tool/test_spec/build.py` で作る）。

## 説明

- **目的**: 回覧板（完全オフラインの BLE すれ違い通信アプリ）の品質を、単体・結合・総合（実機・現地）の 3 段階で確かめる。
- **対象**: iPhone（iOS 16.1 以上）・Android（8.0 以上）・Mac（macOS 11 以上）。ソースは GitHub tsukuba-cojt/sano。
- **場合分け**: カテゴリ: 正常系（要件・要求仕様どおりの使い方）／例外系（想定外の入力・操作、電波や端末の障害）。
- **適用**: 機能・画面・データ（質と量）・通信・処理条件（台数・件数・距離・時間）・同時アクセス・端末環境・障害・電池。
- **結果の書き方**: OK／NG／未実施 と、確かめた日付と方法（自動テスト・エミュレータ・実機）。未実施は実施するチケット番号。
- **自動テスト**: flutter test（2026-11-04 時点 356 件、すべて成功）。単体・結合の「自動テスト」はこの実行結果。
- **大量ユーザー**: 実機を何百台も集められないため、模擬電波の上で 200〜2,000 台を動かして全員に届く時間を測る（結合テスト）。誰とでも同じ確率で出会う理想化した条件なので、地理的な制約は一列に並べたテストで別に確かめる。
- **テストデータ**: 「テストデータ」シートの TD1〜TD10。自動テストはテストコードで作る。実機で使う大量データは開発者メニュー（設定の「バージョン」を 7 回押すと出る、#152）で入れる。
- **予定**: 総合テストは 2027/2/5 までの 4 周（実機の基礎 → 実機のメッシュ → 多人数・長時間 → 利用者テスト）で行い、結果をこの表に書き足す。
