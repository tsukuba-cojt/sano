# 回覧板 UI 設計 v2（高齢者を含む全員向け）

最終更新: 2026-10-16（v1: 2026-10-11）

根拠: デジタル庁デザインシステム（DADS）、WCAG 2.2 AA、Apple HIG、Android アクセシビリティ、高齢者 UI 研究、やさしい日本語ガイドライン。v2 は [08_use_cases.md](08_use_cases.md) の仕様変更を反映した版。変更・追加した行の末尾に「（v2: C01）」のように変更 id を付ける。

## 1. 見た目の方針 — 「市役所の掲示板」
- 白地（カード #FFFFFF）、ページ背景 #F2F2F2、本文 #1A1A1A、副次 #4D4D4D（#767676 より薄くしない）。
- 自治体ブルー #0017C1（主ボタン・ヘッダ・リンク）、押下 #00118F。
- 緊急・取消 #EC0000 / 文字 #CE0000。注意 #C74700。完了 #197A4B。公式バッジは青地白文字、スタッフは白地青枠、住民投稿は灰枠。（v2: C09）
- 緊急色 #EC0000 は 公式の避難情報・注意喚起カードの上辺の赤帯（白文字「避難」「注意」）と、前面で緊急が届いたときの帯「避難情報が 届きました ▶ 見る」だけに使う。注意色 #C74700 は「訓練」タグ。「終わりました」タグは灰枠。（v2: C03, C05, C23, C01）
- 枠線 1px #949494（意味のある線）/ #CCCCCC（装飾）。角丸 4px 以下。影なし。グラデーション・半透明・紫・絵文字アイコン・点滅・バウンスは禁止。
- フォントは OS 標準の日本語フォント（追加同梱なし）。ウェイトは Regular / Bold のみ。

## 2. タイポグラフィ（既定スケール、OS 拡大設定に追従）
| 用途 | サイズ |
|---|---|
| 画面タイトル | 24 Bold |
| お知らせ見出し | 22 Bold（折り返し、省略しない） |
| 本文 | 18 Regular、行間 1.6（ふりがな表示時は 2.0）（v2: C25） |
| メタ情報（場所・時刻・発信元） | 16 Regular |
| ボタン | 18 Bold |
| タグ | 16 Bold |
| 中継役の状態表示 | 24 Regular 3 行（全画面「大きく 表示する」も同じ）（v2: C04） |
| 注意・ヒント（期限・種別・時計ずれ） | 16 Regular（v2: C02, C12） |

設定の「文字の大きさ」= 標準 1.0 / 大きい 1.25 / とても大きい 1.5 を `MediaQuery.textScaler` に乗算。

## 3. 操作
- 主ボタン: 高さ 56、幅いっぱい、青地白文字。1 画面に 1 つ。
- 副ボタン: 高さ 56、白地青枠青文字。取り消しの副ボタンだけ赤枠赤文字。（v2: C01）
- すべてのタップ対象 48×48 以上、隣接 8 以上。
- 下部タブ 3 つ「お知らせ」「グループ」「設定」（アイコン + 文字ラベル常時表示）。ハンバーガーなし。
- ヘッダ左に「＜ もどる」文字付き。
- 一覧更新はボタン「更新」を置く（プルリフレッシュは併用のみ）。
- Semantics の規則（R-30）: すべての画面で読み上げ順は視覚順と同じ。カードは 1 つの Semantics ラベル（種別・役割・新着・見出し・場所・時刻・発信元の順）。状態帯・固定枠・帯・タグ・ボタン・スイッチにラベルを付け、装飾（区切り線・赤帯の色）は excludeSemantics。VoiceOver / TalkBack で ホーム・詳細・書く・参加・設定 を順に読めることをリリース前に確認する。（v2: C19）

## 4. 画面

### 4.1 はじめに（初回のみ）
1. 「回覧板」説明 1 文 + 図なし。「このアプリは、近くのスマホと Bluetooth で お知らせを 交換します。インターネットは 使いません。届くまで 時間が かかるので、避難の 呼びかけは 防災無線や ラジオでも 確かめてください。」（v2: C11）
2. 「Bluetooth を 許可する」主ボタン → OS ダイアログ（「あとで 許可する」で飛ばせる）。
3. 「お知らせが 届いたら 知らせる」: 「新しい お知らせが 届いたら、アプリを 閉じていても スマホの 通知で 知らせます。避難・給水・医療などは 必ず 知らせます。」+「通知を 許可する」主ボタン → OS ダイアログ（「あとで 許可する」で飛ばせる）。（v2: C05）
4. 「お願い」: ①アプリを 上に スワイプして 終了しないでください ②Bluetooth を 切らないでください ③電池が 少なくなると ゆっくり 交換します ④出かけるときは、スマホを カバンの 中ではなく、画面を 点けて 手に 持つと 届きやすく なります ⑤（iPhone のみ）電池が 切れて 充電したら、アプリを 一度 開いてください。続けて「知っておいて ほしいこと」: 電波に 乗るのは アプリの 目印（番号）だけです。名前・電話番号・場所は 乗りません ／ お知らせは 暗号化していません。近くの スマホを 通って 広がります ／ 電池を 使います（実測後に「電池は 1日に 約 □% 使います」へ差し替え。仮の数字は出さない）。文言はプライバシーポリシー・利用規約と一字一句同じ。（v2: C11, C07, C06）
5. 「表示名」（任意、既定「名前なし」）。説明「本名で なくて かまいません。役割が 分かる 名前を おすすめします（例: 3班 佐藤、〇〇小学校 受付）」。（v2: C11）
6. 「はじめる」。

### 4.2 お知らせ一覧（ホーム）
- 上部に状態帯（灰地）: 1 行目「近くの人と 交換中 ・ 近くの端末 2台 ・ 最後に 交換したのは 10月1日 午後3時（14日前）」（当日は時刻のみ）/ 停止中は「交換が 止まっています」（赤文字）＋「再開する」ボタン。必要なときだけ注意行を 1 行（優先順 ①30 日以上無交換「30日以上 だれとも 交換していません。人の 集まる 場所で アプリを 開いてください。人が 少ない 地域では ふつうです」 ②近くの端末 0 台が 30 分「iPhone どうしは 画面が 消えていると 見つけられません。画面を 点けて 1分 待ってみてください」 ③最後の交換から 6 時間以上「6時間 以上 新しい お知らせが 届いていません。外に 出るときは 画面を 点けて 手に 持つと 届きやすく なります」 ④長持ち中「電池を 長持ち させるため、ゆっくり 交換しています」）。注意色は使わない。注意行の右に副ボタン「画面を 点けたままにする（30分）」→ 注意行が「画面を 点けたままです（残り 25分）［やめる］」に変わる（残量 20% 未満なら確認。背面に行ったら解除）。時計が近くの端末と 1 時間以上ずれていれば「この スマホの 時計が 近くの 端末と 2日 ずれています」。（v2: C07, C12）
- 中継役（設定でオン）のときは状態帯を 24pt の 3 行に置き換える: 「中継役として 動いています ・ 近くの端末 3台」「最後に 受け取ったのは 10月1日 午後3時 ・ 最後に 渡したのは 午後3時12分（5件）」「保存 1,240件（〇〇町内会 45件）」。iPhone でアプリが前面でないときは「アプリを 開いてください」。公式の避難情報・注意喚起が届いたら 1 行「避難の お知らせが 届きました」。副ボタン「大きく 表示する」→ §4.8。未参加でも表示。（v2: C04）
- 前面で公式・スタッフの避難情報・注意喚起が届いたら状態帯の下に赤地白文字の帯「避難情報が 届きました ▶ 見る」（複数は「避難情報が 2件 届きました」。1 本だけ。タップまで残す。点滅なし）＋振動 3 回。（v2: C05）
- 訓練投稿が 1 件以上あれば帯「訓練の お知らせが N 件 あります。本物の 災害では ありません」。（v2: C23）
- 参加中グループの閉鎖と後継コードが届いたら文字だけの帯「『〇〇市 防災課』は 新しい 参加コードに 変わったと 届きました。広報紙の 番号と 同じときだけ、グループ画面から 6 桁を 入れてください」（ボタンなし）。（v2: C24）
- 未読があれば「新しい お知らせが 3件 あります」。「新しい」は最後にホームを表示してから届いたもので、一覧を表示した（または「更新」を押した）時点で既読になる。（v2: C03）
- 固定枠「いま 出ている 避難の お知らせ」: 参加中グループの公式の避難情報・注意喚起で期限内・未取消・未置き換えのものを出された時刻の新しい順に最大 3 件（なければ枠を出さない）。各行に見出し・発信元名・グループ名。枠の下に 16pt「防災無線・テレビ・市の ホームページでも 確かめてください」。訓練投稿は入れない。（v2: C03）
- 日付見出しは届いた時刻で「今日 届いた」「きのう 届いた」「10月9日（木）に 届いた」。並び順も届いた時刻の新しい順。（v2: C12）
- カード（全体がタップ領域、高さ 72 以上）:
  1. 行 1: 種別タグ（例「物資」）・「公式」/「スタッフ」/「住民」バッジ・「新着」タグ・「書きなおし」または灰枠「終わりました」タグ・注意色「訓練」タグ。公式の避難情報・注意喚起は上辺に赤帯「避難」「注意」（v2: C01, C03, C23）
  2. 見出し 22 Bold（例「〇〇小学校に 水と 毛布が とどきました」）
  3. 本文 1 行目（全角 30 文字まで、末尾「…」。空なら出さない）16（v2: C03）
  4. 「場所: 〇〇小学校（避難所）」16
  5. 「2026年10月11日 午後3時20分」16（出された時刻。未来または 24 時間以上前なら灰色にして「（出した スマホの 時計が ずれている かもしれません）」）・ 右端に「〇〇市 防災課」。給水・炊き出し・物資・医療は「午後6時まで」を併記し、1 時間以内なら「まもなく 終わります」タグ（v2: C02, C12）
  6. 取り消し済みは受信端末では一覧から消す（本文も端末から消える）。発信者本人の端末だけ灰色＋「取り消しました」帯（公式に取り消されたときは「公式により 取り消されました」）。置き換えられた旧版は表示しない（v2: C20, C10, C01）
- グループが複数なら上部に「すべて / グループ名」の切替（セグメント、文字ラベル）。種別での絞り込みは置かない。
- 公式・スタッフ端末は状態帯の下に「住民からの 知らせ: SOS 1件 ・ 無事 12件（20人） ・ 在宅避難 5件（11人）（未返事 N件） ▶ 見る」の帯（薄い青地）。まだ返事をしていない SOS があれば赤地白文字「SOS が N件 あります（まだ 返事を していません） ▶ 見る」にし、増えたときに 3 回振動する。タップで §4.7 の一覧。（v2.1: C21 拡張）
- 主ボタン「お知らせを 書く」（投稿可能なグループに参加しているときだけ表示）。
- 副ボタン「本部に 知らせる（SOS・安否）」（参加中グループのどれかが「住民からの 知らせを 受け付ける」をオンにしていて、自分がそのグループの本部・スタッフでないときだけ。主ボタンの下、投稿不可ならその位置）→ §4.7。（v2.1: C21 拡張）
- 未参加なら中央に「グループに 参加すると お知らせが 届きます」＋主ボタン「グループに 参加する」。その下に「今は 近くの スマホの お知らせを 運ぶだけ しています（近くの端末 N台）」。（v2: C07）

### 4.3 お知らせ詳細
- 右上に「掲示番号 123456」（msg_id の下位 20 ビットを 10 進 6 桁。紙との突合用）。（v2: C19）
- 見出し、タグ列、場所、出された時刻（時計ずれの注記は一覧と同じ）、発信元、本文（18、行間 1.6、選択してコピーできる）、「〇月〇日 〇時 まで」、区切り線、「この端末に 届いた時刻: 午後3時45分（近くの人の スマホから）」「転送 3回」。自分の投稿（公式端末なら同グループの公式投稿も）は「転送 N回」の代わりに「この端末から 渡した: 7台（最後は 午後3時10分）」と説明「近くの スマホに 直接 渡した 数です。その先に 広がった 数は 分かりません」。（v2: C19, C18, C12）
- 書きなおし・終わりましたで置き換えられたお知らせは、区切り線の下に灰色で常時「前の 内容（午前8時 発信）: 〇〇公園で 給水を しています」（受信端末は見出しと発信時刻だけ。発信者本人の端末は場所・本文も）。「取り消して 新しく 書く」で出されたお知らせは帯「元の 投稿: 〇〇さん」。（v2: C01, C10）
- 副ボタン「読み上げる」（押すと「止める」）: 種別 → 役割 → 見出し → 場所 → 出された時刻 → 発信元 → 本文 の順。Android で日本語音声がなければ「スマホに 日本語の 音声が 入っていません」＋「スマホの 設定を 開く」。（v2: C19）
- 発信者本人なら副ボタンを縦に「終わりました」「書きなおす」「取り消す（赤）」（避難情報には「終わりました」を出さない）。（v2: C01）
  - 「終わりました」: 確認「『〇〇公園の 給水は 終わりました』と 知らせます」→ 送信。見出しは種別ごとの終了文、本文「（10月12日 午後6時10分に 終わりました）」、期限 12 時間。
  - 「書きなおす」: §4.4 を「お知らせを 書きなおす」として開く。
  - 「取り消す」: 確認「終わった お知らせは『終わりました』を 使ってください。取り消すと 本文が 近くの スマホからも 消えます（届くまでに 時間が かかります）」。（v2: C20）
- 公式端末（ホスト・本部コードで昇格）で自分の投稿でないお知らせを開くと副ボタン「公式として 取り消す」「取り消して 新しく 書く」。確認文「『〇〇で 給水』（〇〇さん）を 〇〇市 防災課 として 取り消します。近くの スマホにも 広がります」。スタッフ端末・住民には出さない。（v2: C10）
- 安否確認（「返事の ボタンを 付ける」で出したお知らせ）: タグ「返事を ください」。住民端末では本文の下に注意枠「この お知らせは 返事を 求めて います。当てはまる ボタンを 押してください」と、主ボタン「無事です」、副ボタン「家に います（在宅避難）」「困っています」「助けて（SOS）（赤）」。押すと §4.7 の入力画面が種類を選んだ状態で開く。送った返事は「『無事です』を 送りました（午後3時）。〇〇市 防災課が 受け取りました（午後3時40分）」の枠で示す。本部・スタッフ・出した本人の端末では代わりに「返事 N件」の集計枠と副ボタン「返事を 見る」（§4.7 の一覧をこの安否確認の返事だけに絞って開く）。（v2.1: C21 拡張）
- 送信後「訂正しました。近くの スマホに 広がります」（書きなおし・終わりました）。（v2: C01）

### 4.4 お知らせを書く
0. 最上部に副ボタン「前に 出した お知らせから 作る」: 自分の直近 10 件（期限切れ分も端末に残す。取り消し済みは除く）から選ぶと種別・場所・見出し・本文を引き継ぐ。期限は選び直す。新規投稿（上書きではない）。（v2: C14）
1. 出す グループ（投稿できるグループが 2 つ以上のときだけ）: チェック付き大ボタンで複数選択（最大 5）。既定は前回送った 1 つ目だけ。（v2: C14）
2. 「これは 訓練です」スイッチ（公式・スタッフ端末だけ、既定オフ）。オンで見出し先頭に【訓練】、期限の既定 3 時間。（v2: C23）
   その下に「返事の ボタンを 付ける（安否確認）」スイッチ（公式・スタッフ端末だけ、既定オフ）。オンで種別を「安否・名簿の 案内」、期限 3 日、見出しが空なら「安否確認です。下の ボタンで 返事を してください」。説明「受け取った 人に『無事です』『家に います』『困っています』『助けて』の ボタンが 出ます。返事は 本部と スタッフの 端末に 届きます」。確認文「返事の ボタンを 付けて 送ります。…届くまで 時間が かかります」。（v2.1: C21 拡張）
3. 種別: 大きなボタンを 2 列（16 種、文字ラベル）。種別名は「医療・救護」「安否・名簿の 案内」「トイレ・入浴・洗濯」「店舗・燃料・銀行」に改名。（v2: C15, C11）
4. 場所（任意、テキスト）。
   - 注意枠（1 枠 3 文以内）: 「安否・名簿の 案内」「医療・救護」「支援要請」「被害情報」を選んだとき「本人の 同意が ない 人の 名前・住所・病気・けがは 書かないでください。送った 内容は 近くの スマホに 残り、あとから 消せません」。「避難情報」を選んだとき「避難の 呼びかけは 防災無線や 声でも 伝えてください。このアプリは 届くまで 時間が かかります」。（v2: C11）
   - 期限のヒント（選択中の 1 種別だけ 1 行 16pt）: 支援要請「運ぶ人が 来るまで 時間が かかります。期限は 3日が おすすめです」、店舗・燃料・銀行 / 医療・救護 / 物資「薬の 在庫や 給油、人数など すぐ 変わる ものは 6時間を 選んでください」。（v2: C02）
5. 見出し（必須）: 種別を選ぶと例文（1 種別 最大 3 文）を 1 列ボタンで選び、{ } を埋める。例文は 08 §3.2 C15。{名前} を含む例文はない。（v2: C15, C11）
6. 本文（任意、複数行）。物資のヒント「1人 2本まで。なくなり次第 終わります。」（v2: C15）
7. 有効期限（種別既定）: 2 列の「3時間 / 6時間 / 12時間 / 1日 / 3日 / 7日 / 30日 / 時刻を 決める」。「30日」はスタッフ・公式端末だけ。「時刻を 決める」は「今日 / あした」→「午前6時〜午後10時」（1 時間刻み）の 2 段で、結果「今日 午後5時 まで」。過去の時刻は「終わる 時刻が 過ぎています」で送れない。7 日以上を選ぶと 16pt「長く 残ります。人の 名前や 住所は 書かないでください」。（v2: C02）
8. 時計の注意: 端末時計が 2026 年 1 月 1 日以前、または近くの端末と 24 時間以上ずれているとき、「送る」の前に赤い注意「この スマホの 時計が 合っていません（2026年1月1日）。時計を 直してから 送ってください」＋副ボタン「設定を 開く」。それでも送れる。（v2: C12）
9. 主ボタン「送る」→ 確認「この内容で 送ります。近くの スマホに 広がり、取り消しても 他の スマホからは すぐには 消えません。」（同報は「〇〇市 防災課（公式）、△△町内会（住民）に 送ります（2 件分 広がります）」、訓練は「訓練として 送ります。見出しに【訓練】が 付きます」）→ 送信後「送りました。すれ違う人に 広がります。」（v2: C11, C14, C23）
- 「お知らせを 書きなおす」（詳細から）: 元の種別・場所・見出し・本文で開き、上部に帯「前の お知らせは 消えて、この 内容に 置き換わります」。期限は選び直す。送信後「訂正しました。近くの スマホに 広がります」。（v2: C01）
- 「取り消して 新しく 書く」（公式端末、詳細から）: 帯「元の 投稿: 〇〇さん」、種別・場所を引き継ぎ、本文先頭に「〇〇さんの お知らせを 取り消しました。」を自動挿入。（v2: C10）

### 4.5 グループ
- 参加中の一覧（名前、コード、役割: 本部 / スタッフ / 参加者）。（v2: C09）
- 副ボタン「グループに 参加する」→ 6 桁入力画面（数字キーパッド自動、1 桁 48 幅、入力中に近隣から受け取った名前があれば表示、「参加する」）。案内文「番号は、市の 広報紙・ホームページ・町内会の 案内に 載っています。同じ 番号か 確かめてください。同じ 名前が 2つ あるときは 係の人に 確かめてください」。副ボタン「番号が 分かりません」→「近くで 流れている グループ」: 端末が保存している未参加グループを新しい順に最大 3 件「グループ名 ／ 作った人: 〇〇市 防災課 ／ 12分前に 受け取りました」（問い合わせ先があれば併記）。タップで 6 桁が入る。空なら「近くの スマホから グループの 名前が 届くと ここに 出ます」。参加直後に 1 回「参加する 前に 届いていた お知らせも 見られます」。（v2: C22, C24）
- 副ボタン「グループを 作る」→ 名前、「参加者も 投稿できる」スイッチ、「住民からの 知らせを 受け付ける」スイッチ（既定: 受け付けない）、「問い合わせ先・ひとこと」（任意、100 文字）、作成 → 参加コード（3 桁区切り「123 456」）と QR、「本部コード」（8 桁）と 1 文「本部コードは 防災課の 端末だけに 教えてください」、「スタッフコード」（8 桁）と 1 文「スタッフコードは 避難所や 病院・薬局・電力・バスの 担当者に 教えてください」、「この 8 桁は 紙に 書いて 2 人以上で 保管してください。端末を 替えたときに 使います」。（v2: C09, C21, C24）
- グループ詳細: 名前、コード・QR、問い合わせ先。参加者には副ボタン「本部コードを 入れる」「スタッフコードを 入れる」（2 画面。本部は確認「この端末を 本部端末に します」。グループ情報が届いていなければ「グループの 情報が まだ 届いていません。近くで もう一度 試してください」、不一致なら「番号が ちがいます」。昇格時に「この グループでの 発信元名」を入れる。初期値は公式ならグループ名、スタッフなら表示名。説明「施設名・部署名を 入れてください。個人名は 入れないでください」）。本部端末（ホスト・本部コードで昇格）には両コードの表示、「グループの 情報を もう一度 広げる」、「参加者の 投稿: できる / 発信者だけ」「困りごとを 受け付ける」の切替、「コードを 作り直す」（説明「新しい 番号は これから 入れる 端末に 効きます。すでに 入れた 端末は そのままです」）、「新しい グループに 引っ越す」（漏えい時の手順）、「訓練の お知らせを すべて 取り消す」。中継役がオンの端末では 8 桁コードの表示と切替を隠し「先に 中継役を やめてください」。「このグループから 抜ける」（中継役中は案内「先に 中継役を やめてください」）。（v2: C09, C24, C23, C04）

### 4.6 設定
- 文字の大きさ（標準 / 大きい / とても大きい）
- ふりがな（つける / つけない、既定「つけない」）（v2: C25）
- ことば / Language（OS に追従。ja / en / zh-Hans / vi / pt / ko）（v2: C25）
- 表示名（説明は §4.1-5 と同じ。住民投稿用。昇格したグループの発信元名はグループ詳細で）（v2: C11, C09）
- 電池（ふつう / 長持ち）。実表示 1 行「今の 残量 35%（充電中）・ 今は ふつう」。説明「電池が 20% より 少なくなると 自動で 長持ちに なり、50% を 超えると ふつうに 戻ります。充電中は ふつうです」。（v2: C06）
- 通知（ぜんぶ 知らせる / 公式と 大事なものだけ 知らせる（既定）/ 知らせない。説明「避難・給水・医療などは 必ず 知らせます。音が 聞こえにくい方は スマホの『LED フラッシュ通知』を オンに してください」。「通知を 許可する」で OS の許可をあとから求められる。月 1 回の確認通知はこの設定に従う）（v2: C05, C07）
- 通信（開始 / 停止、状態、省電力除外の案内 [Android]、「アプリを終了しないでください」）
- 中継役として 使う / 使わない（既定: 使わない）。オンにした直後に案内「電池を たくさん 使います。充電しながら 使ってください」「iPhone は 画面を 消すと 交換できません」（Android は省電力除外を先に案内）。説明文「中継役の 端末は 参加している グループの 名前を 近くの 端末に 知らせます」。「交換の 音: 鳴らす / 鳴らさない」（既定: 中継役のとき 鳴らす）。「中継役を やめる」は確認 1 回。中継役中は「通信を 止める」を押すと「先に 中継役を やめてください」。（v2: C04, C17）
- 通信の状態（診断画面へ: 近くの端末、最近の交換ログ、保存件数をグループ別に「〇〇町内会: 45件（最新 午後3時20分）／ ほかのグループ（中継のみ）: 310件 ／ 取り消し: 4件」、送った件数（累計）、最後に 渡したのは、ノード ID、今の時刻、近くの端末との 時計の差、表示できない お知らせ N 件（新しい 版）、「最近 変わった お知らせ（7 日）」（掲示番号・見出し・いつ変わったか。取り消し分は番号と時刻のみ）、本部端末には「公式取消の 記録」（90 日、文章としてコピー））（v2: C18, C12, C13, C19, C10）
- このアプリについて（バージョン、既知の制約、「知っておいて ほしいこと」= §4.1-4 と同文）（v2: C11）

### 4.7 本部に 知らせる・住民からの 知らせ（v2: C21、v2.1 で SOS・安否・在宅避難に拡張）
- 入力画面「本部に 知らせる」（安否確認の返事なら「安否確認に 返事を する」）:
  - 1 枚目「どれを 知らせますか」: 大きなボタン 4 つ（高さ 72 以上、ボタンの下に 1 行の説明）。「助けて（SOS）」（赤地白文字。けが・閉じこめ・急病など、すぐに 助けが 必要）、「無事です」、「家に います（在宅避難）」、「困っています」（水・食べ物・薬・トイレ・電気などが 足りない）。下に赤枠「命に かかわる ときは 119番・110番に 電話してください。つながらない ときは 大きな 声や 笛で 近所に 知らせてください」。送り先のグループが複数なら上に選択。その下に「送った 知らせ」（種類タグ・見出し・送った時刻・「まだ 受け取りの 返事は ありません」/「〇〇市 防災課が 受け取りました（午後3時10分）」）。
  - 2 枚目（種類ごと）: 人数「1人 / 2人 / 3人 / 4人 / 5人以上」（既定 1人。見出しは「助けが 必要な 人数」「無事な 人数（自分を 入れて）」など）。在宅避難・困っていますは困りごと 6 択（複数可。困っています は 1 つ以上必須）「水・食べ物が ない」「薬・医療が 必要」「動けない・助けが 必要」「トイレが 使えない」「電気・ガスが 止まっている」「その他」。無事です・在宅避難は「けがを している 人が いる」と「名前（なくても よい、16 文字）」（ヒント「家族を さがす ときに 役立ちます。書かなくても 送れます」。既定は設定の表示名）。全種類に「場所」（40 文字、ヒント「町名と 目印だけ（番地は 書かない）」。SOS は「できるだけ 書いてください」）と「ひとこと」（40 文字）。注意枠「近くの スマホを 通って 本部に 届きます。暗号化 されないので、病名や 番地は 書かないでください」。自動の見出しを「見出し: 【無事】山田 花子 さんは 無事です（3人）」と示す。主ボタン「送る」（SOS は「助けを 求める 知らせを 送る」）。
  - 確認「近くの スマホを 通って、〇〇市 防災の 本部・係の 人に 届きます。届くまで 時間が かかります。急ぐときは 近所の 人にも 声を かけてください。名前は 送りません（名前「〇〇」も 送ります）」。送信後「送りました。本部が 受け取ると、通知と『送った 知らせ』で 分かります」。
  - 同じ種類を 30 分（SOS は 10 分）以内に送り直そうとしたら「さきほど 送りました。受け取りの 返事を 待ってください」。
- 一覧「住民からの 知らせ」（本部・スタッフ端末。ホームの帯、グループ詳細「住民からの 知らせを 見る」、安否確認の「返事を 見る」から）:
  - 上に未返事の SOS の赤枠「まだ 返事を していない SOS が N件 あります。場所を 確かめて、係の 人を 向かわせてください」、集計枠「届いた 知らせ N件 / SOS 1件 ・ 無事 12件（20人） ・ 在宅避難 5件（11人） ・ 困りごと 3件 / まだ 返事を していない: N件」と注記「同じ 人が 何回か 送ることも あります。人数は 目安です」。
  - 絞り込み「すべて / まだ 返事を していない / SOS / 無事 / 在宅避難 / 困りごと」。カードは種類タグ（SOS 赤地白文字、無事 緑枠、在宅避難 青枠、困りごと 橙枠）・見出し・場所・ひとこと・届いた時刻・状態（「まだ 返事を していません」橙 / 「受け取りました と 返しました（午後3時40分）」緑）。未返事の SOS は赤枠。
  - 下に主ボタン「表示中の N件に 受け取りましたと 返す」（確認あり）と副ボタン「表示中の 知らせを 文章で コピー」（紙の台帳・無線で伝える写し。「10月23日 午後3時10分 ／ 見出し ／ 場所 ／ ひとこと ／ 受け取り済み ／ 番号 123456」を 1 行ずつ）。
- 詳細: 種類タグ・番号・見出し、状態枠、「種類・人数・けが・困っている こと・名前・場所・ひとこと・グループ・届いた（送った）時刻・転送・有効期限」の表。本部・スタッフ端末は主ボタン「受け取りました と 返す」（SOS なら赤枠「助けを 求めて います。場所を 確かめて 係の 人を 向かわせ、『受け取りました』を 返してください」）。送った本人は「〇〇市 防災課が 受け取りました（午後3時10分）。対応の 約束では ありません。急ぐ ときは 近所の 人にも 声を かけてください」と、副ボタン「取り消す（もう 大丈夫です）」（赤）。安否確認への返事なら「安否確認の お知らせを 見る」。
- 通知（本部・スタッフ端末、背面のとき）: SOS は 1 件ずつ urgent「住民から SOS が 届きました ／ 場所: 〇〇町 公民館の 裏 ／ 2人 ／ 2階に います」（グループごと 10 分 3 件まで）。ほかは 5 秒まとめて important「住民からの 知らせが N件 届きました ／ 無事 3件（5人） ・ 在宅避難 1件（2人）」。送った本人には「〇〇市 防災課が 受け取りました ／ 【無事】…」。「知らせない」なら出さない。
- グループを作る画面・グループ詳細のスイッチ「住民からの 知らせを 受け付ける」（既定オフ）。説明「オンにすると、参加した 人が『本部に 知らせる』から SOS・無事です・在宅避難・困っています を 送れます。見る 係の 人を 置いてから オンにしてください」。安否確認の返事はオフでも届く。

### 4.8 中継役の「大きく 表示する」（v2: C04）
- 白地黒文字の全画面。§4.2 の 3 行（24pt）と、公式の避難情報・注意喚起が届いたときの 1 行「避難の お知らせが 届きました」だけ。「最近 変わった お知らせ（7 日）」へ 1 タップで開ける。どこをタップしても戻る。輝度は変えない。

## 5. 文言規則（やさしい日本語）
- 一文一情報。「です・ます」。外来語・略語は避ける（「Bluetooth」は固有名詞としてそのまま）。
- 日時は「2026年10月11日 午後3時20分」。相対表現を併記「（2時間前）」。日本語以外の表示では 24 時間制「15:20」。（v2: C25）
- 分かち書きに近い読点・スペースで区切る（例「近くの スマホに 広がります」）。
- 通知の文面は「見出し ／ 場所: 〇〇小学校 ／ 本文 1 行目（30 文字）」。「【避難】」「【注意】」の接頭辞は公式の避難情報・注意喚起だけ。本文 1 行目を入れるのは避難情報・注意喚起・避難所・給水・炊き出し・物資だけ。（v2: C05）
- 終了文（「終わりました」）は種別ごとに固定: 避難所「{場所}の 避難所は 閉じました」、交通「{場所}は 通れるように なりました」、給水・炊き出し・物資「{場所}の {給水}は 終わりました」、店舗「{場所}の 販売は 終わりました」、注意喚起（公式のみ）「{場所}の 注意喚起は 解除されました」、その他「{場所}の お知らせは 終わりました」。（v2: C01）
- 定型見出しの各言語の固定訳は docs に一覧化し、自治体の多文化共生担当が確認する。自由文は翻訳しない。（v2: C25）
